# v1.3.0

## 日本語

前の安定版 v1.2.0 からの変更です。

### 変更点

- チケットの編集フォームを `Ctrl+Enter` または `Cmd+Enter` で保存できます。チケット詳細でも、新規コメントの入力欄で同じキーを押すと投稿できます。本文のインライン編集では、IME 変換中の確定操作で保存が走らないようにしました。[PR #66](https://github.com/wamukat/kanbalone/pull/66)
- ボード上で修飾キーなしの `/` を押すと、Kanban と List の検索欄にフォーカスします。Group と「グループ指定なし」でも、大規模表示用のチケット検索欄が表示されていれば使えます。テキスト入力中やダイアログを開いている間は、検索へフォーカスを移しません。[PR #66](https://github.com/wamukat/kanbalone/pull/66)
- Kanban と List のチケットタイトルに、テーマのアクセント色でキーボードフォーカスの枠を表示します。強制カラーモードではシステムの強調色を使います。Group と「グループ指定なし」の完了行には、List と同じ薄い背景色を付けます。[PR #67](https://github.com/wamukat/kanbalone/pull/67)

### 更新時の注意と制約

- v1.2.0 からの更新では、データベースのスキーマ、保存形式、API の互換性に変更はなく、追加の移行作業は不要です。
- `/` は検索欄が表示されているビューで使用できます。コメント投稿のショートカットは新規コメントが対象です。

## English

Changes since the previous stable release, v1.2.0.

### Changes

- Press `Ctrl+Enter` or `Cmd+Enter` to save the ticket edit form. In ticket details, use the same shortcut in the new-comment field to post a comment. Confirming text during IME composition no longer triggers a save in the inline ticket body editor. [PR #66](https://github.com/wamukat/kanbalone/pull/66)
- Press unmodified `/` on a board to focus the search field in Kanban or List. The shortcut also works in Group and No Group when the large-view ticket search is visible. Focus stays in place when you are entering text or a dialog is open. [PR #66](https://github.com/wamukat/kanbalone/pull/66)
- Kanban and List show a theme accent outline when a ticket title receives keyboard focus. Forced colors mode uses the system highlight color. Resolved rows in Group and No Group use the same subtle background as resolved rows in List. [PR #67](https://github.com/wamukat/kanbalone/pull/67)

### Upgrade notes and limitations

- The upgrade from v1.2.0 keeps the database schema, storage format and API compatible. No additional migration steps are required.
- The `/` shortcut requires a visible search field. The comment shortcut applies to new comments.
