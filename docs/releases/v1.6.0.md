# v1.6.0

## 日本語

前の安定版 v1.5.0 からの変更です。

### 変更点

- **リスト**で複数のレーンを、**カンバン**と**リスト**で複数のタグを選べます。各項目では選択したいずれかに一致するチケットを表示し、レーンとタグを両方指定した場合は両方の条件を満たすチケットを表示します。未選択の項目はすべてが対象です。選択はこのブラウザーにボードごとに保存します。 [PR #88](https://github.com/wamukat/kanbalone/pull/88)
- カンバンとリストのツールバーから **完了状態** フィルターを削除しました。両方の画面に未完了と完了のチケットを表示し、リストでは完了レーンを選んで絞り込めます。**アーカイブを含める** は押すたびに表示を切り替えるボタンになりました。グループの **未完了のみ** とカスタムビューの完了条件は引き続き使えます。 [PR #87](https://github.com/wamukat/kanbalone/pull/87)
- ボード内のチケット一覧 API に `lane_ids` と `tag_ids` を追加しました。カンマ区切りの ID で指定でき、従来の `lane_id`、`lane`、`tag` も引き続き使えます。レーンとタグのパラメーターはそれぞれ省略でき、指定する場合は各1種類までです。 [PR #88](https://github.com/wamukat/kanbalone/pull/88)
- リリース候補のビルド・検証をテストと並列に実行し、旧バージョンからのアップグレード・復元検証でコンテナを停止する時間を短縮しました。公開には検証済みの候補イメージを使います。 [PR #86](https://github.com/wamukat/kanbalone/pull/86)

### 更新時の注意と制約

- v1.5.0 からの更新に手動のデータ移行は不要です。更新前に Kanbalone とほかの書き込み元を停止し、SQLite データベースと添付画像をまとめてバックアップしてください。 [バックアップ手順](https://github.com/wamukat/kanbalone/blob/v1.6.0/docs/ja/migration-guide.md#database-and-image-backup)
- 旧バージョンのカンバンとリストの完了条件は更新後に解除されます。アーカイブ設定と、ボードに存在するレーン・タグの選択は自動で引き継ぎます。レーンの複数選択はリストで使えます。 [ユーザーガイド](https://github.com/wamukat/kanbalone/blob/v1.6.0/docs/ja/user-guide.md)
- 公開 Docker イメージの対応プラットフォームは `linux/amd64` です。

## English

Changes since the previous stable release, v1.5.0.

### Changes

- Select multiple lanes in **List** and multiple tags in **Kanban** and **List**. A ticket can match any selected value within a filter. When both lane and tag filters are active, the ticket must match both. An empty selection includes all values. This browser remembers selections per board. [PR #88](https://github.com/wamukat/kanbalone/pull/88)
- Removed the **Completion** filter from the Kanban and List toolbars. Both views show open and resolved tickets, and you can choose a completion lane in List to focus on finished work. **Include archived tickets** is now an on/off button. **Open only** in Groups and completion conditions in Custom views remain available. [PR #87](https://github.com/wamukat/kanbalone/pull/87)
- The board ticket collection API accepts comma-separated IDs in `lane_ids` and `tag_ids`. Existing requests using `lane_id`, `lane`, or `tag` continue to work. Use at most one lane parameter and one tag parameter. Omit a field to include all its values. [PR #88](https://github.com/wamukat/kanbalone/pull/88)
- Release candidate builds and image verification run alongside tests. Containers now stop faster during upgrade and restore verification. Publication uses the verified candidate image. [PR #86](https://github.com/wamukat/kanbalone/pull/86)

### Upgrade notes and limitations

- Upgrading from v1.5.0 requires no manual data migration. Before upgrading, stop Kanbalone and other database writers, then back up SQLite and attachments together. [Backup procedure](https://github.com/wamukat/kanbalone/blob/v1.6.0/docs/en/migration-guide.md#database-and-image-backup)
- Upgrading clears the old completion selection in Kanban and List. The archive setting and selections for lanes and tags that still exist on the board carry over automatically. Lane multi-select is available in List. [User guide](https://github.com/wamukat/kanbalone/blob/v1.6.0/docs/en/user-guide.md)
- The published Docker image supports `linux/amd64`.
