# v1.4.0

## 日本語

前の安定版 v1.3.0 からの変更です。

### 変更点

- **カスタムビュー**で複数のボードを横断するチケット一覧に名前を付けて保存できます。対象ボード、ボードごとのタグ、完了状態で絞り込み、ボード別の件数、本文と最終コメントの抜粋を確認できます。抜粋は展開して全文を読めます。表示設定は一時的に切り替えられ、チケットは所属ボードの通常の詳細画面で開けます。[PR #70](https://github.com/wamukat/kanbalone/pull/70)
- Group と「グループ指定なし」に **未完了のみ** を追加しました。初期状態はオフで、このブラウザーでの選択をボード別に保存します。「アーカイブ済みを表示」と組み合わせて使えます。対象の未完了子チケットがある完了親は、理由付きの操作できない参照行として残ります。グループ全体の進捗と件数は引き続き表示します。[PR #71](https://github.com/wamukat/kanbalone/pull/71)

### 更新時の注意と制約

- 更新前に Kanbalone とほかの書き込み元を停止し、SQLite データベースと添付画像をまとめてバックアップしてください。起動時に保存ビュー用のテーブルと更新検出用トリガーが自動で追加されます。手動での移行や既存 API の変更は不要です。以前の版に戻す場合は、更新前のバックアップを v1.3.0 のイメージで復元してください。[DBと添付画像のバックアップ](https://github.com/wamukat/kanbalone/blob/v1.4.0/docs/ja/migration-guide.md#database-and-image-backup)
- 保存ビューはデータベース全体のバックアップに含まれます。単一ボードの JSON 出力で移せるのはボードデータです。カスタムビューではアーカイブ済みチケットを除外し、条件未設定のボードやタグが全てオフのボードは 0 件になります。削除された参照は警告を表示し、条件を広げません。

## English

Changes since the previous stable release, v1.3.0.

### Changes

- Use **Custom views** to save named lists across boards. Filter by boards, per-board tags and completion, and see counts per board with expandable excerpts from the ticket body and latest comment. You can change display settings temporarily and open each ticket in the usual detail view for its board. [PR #70](https://github.com/wamukat/kanbalone/pull/70)
- Group and No Group now offer **Open only**. It starts off, and the browser remembers the setting per board. Use it together with **Show archived tickets**. A completed parent with a matching open child stays visible as a labelled, non-interactive reference. The overall Group counts and progress stay visible. [PR #71](https://github.com/wamukat/kanbalone/pull/71)

### Upgrade notes and limitations

- Before upgrading, stop Kanbalone and other database writers, then back up SQLite and attachments together. Startup adds the saved-view tables and change-tracking triggers automatically. Existing API calls continue to work. To roll back, restore the pre-upgrade backup with the v1.3.0 image. [Database and image backup](https://github.com/wamukat/kanbalone/blob/v1.4.0/docs/en/migration-guide.md#database-and-image-backup)
- Full database backups include saved views. Single-board JSON exports transfer board data only. Custom views exclude archived tickets. Boards without a rule or with all tags switched off contribute zero matches. Deleted references are flagged, and the filter keeps its existing scope.
