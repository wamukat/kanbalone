# v1.5.0

## 日本語

前の安定版 v1.4.0 からの変更です。

### 変更点

- **カスタムビュー**で、ボードごとに「すべてのレーン」または選択したレーンに絞り込めます。レーン条件はタグ条件と完了条件に組み合わせられます。ボードの表示順を保ったまま、各ボード内を従来の順序、本文・コメントの最新更新順、または優先度の高い順で表示できます。[PR #73](https://github.com/wamukat/kanbalone/pull/73)
- 画面間でボタンや入力欄などの見た目を揃え、ダークテーマのアクティビティテキストと Markdown リンク、リモートインポートのチェックボックス、コメント編集欄の余白を調整しました。最初のボードを作る案内も表示言語に合わせました。[PR #83](https://github.com/wamukat/kanbalone/pull/83)
- サイドバーでタグ色コードの7文字すべてが読めるようにし、タグの編集を開いても周囲のコントロールが縮まないようにしました。完了レーンの保存やリモートインポートなど、無効な主操作ボタンをライト・ダーク両テーマで見分けやすくしました。[PR #84](https://github.com/wamukat/kanbalone/pull/84)

### 更新時の注意と制約

- 更新前に Kanbalone とほかの書き込み元を停止し、SQLite データベースと添付画像をまとめてバックアップしてください。起動時に本文・コメントの内容更新時刻を保存するテーブルが自動で追加されます。手動での DB 移行は不要です。v1.4.0 に戻す場合は、更新前のバックアップを v1.4.0 のイメージで復元してください。[DBと添付画像のバックアップ](https://github.com/wamukat/kanbalone/blob/v1.5.0/docs/ja/migration-guide.md#database-and-image-backup)
- 既存ビューは全レーン・従来順のままです。既存の API リクエストはそのまま使え、更新で新項目を省略すると保存済みの条件を保ちます。更新・復元後は保存したカスタムビューのカーソルを破棄し、先頭ページから取得してください。選択レーンが0件なら結果も0件です。削除されたレーンは警告を表示し、絞り込みを広げません。[API の使用例](https://github.com/wamukat/kanbalone/blob/v1.5.0/docs/ja/api-examples.md)
- 過去の本文編集時刻は復元できないため、初期値には課題の作成時刻と記録済みのコメント投稿・内容編集時刻を使います。以後の内容更新順には、実際の本文変更とコメントの投稿・内容編集を反映します。コメントを削除しても最後に記録した時刻を保ちます。DB 全体のバックアップは履歴を保持し、単一ボードの JSON インポートは取り込み時刻から履歴を開始します。[移行ガイド](https://github.com/wamukat/kanbalone/blob/v1.5.0/docs/ja/migration-guide.md)

## English

Changes since the previous stable release, v1.4.0.

### Changes

- In **Custom views**, use all lanes or choose specific lanes for each board. Lane conditions combine with tag and completion conditions. Board sections keep their order, and you can order tickets within each board by the original position, latest body or comment activity, or highest priority first. [PR #73](https://github.com/wamukat/kanbalone/pull/73)
- Buttons and input fields are more consistent across screens. Dark-theme activity text and Markdown links, remote-import checkboxes, and padding in the comment editor have been adjusted. The first-board hint follows the display language. [PR #83](https://github.com/wamukat/kanbalone/pull/83)
- All seven characters of tag color codes are readable in the sidebar, and opening the tag editor keeps surrounding controls from shrinking. Disabled primary actions, including saving a completion lane and importing a remote issue, are easier to distinguish in light and dark themes. [PR #84](https://github.com/wamukat/kanbalone/pull/84)

### Upgrade notes and limitations

- Before upgrading, stop Kanbalone and other database writers, then back up SQLite and attachments together. Startup adds a table for body and comment activity times automatically. No manual database migration is required. To roll back to v1.4.0, restore the pre-upgrade backup with the v1.4.0 image. [Database and image backup](https://github.com/wamukat/kanbalone/blob/v1.5.0/docs/en/migration-guide.md#database-and-image-backup)
- Existing views keep all lanes and their original order. Existing API requests continue to work. Updates that omit the new fields preserve the saved settings. Discard saved custom-view cursors after upgrading or restoring, and query from the first page. Selecting zero lanes matches zero tickets. Deleted lanes are flagged without broadening the filter. [API examples](https://github.com/wamukat/kanbalone/blob/v1.5.0/docs/en/api-examples.md)
- Historical body-edit times cannot be recovered. Initial activity uses ticket creation and recorded comment posts and content edits. Future body changes, new comments and comment content edits advance the recorded time. Deleting a comment preserves that time. Full database backups retain the history. For a single-board JSON import, activity starts at import time. [Migration guide](https://github.com/wamukat/kanbalone/blob/v1.5.0/docs/en/migration-guide.md)
