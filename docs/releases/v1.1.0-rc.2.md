# v1.1.0-rc.2

## 日本語

v1.1.0の第2リリース候補です。GitHub Releasesの最新安定版とDockerの`latest`はv1.0.0のままです。

### v1.1.0-rc.1からの変更

- 公開ワークフローは、ドライランでビルド・テストし、ローカルで検証したDockerイメージを、候補artifact IDで指定して公開するようになりました。公開時は候補の出所と整合性を確認し、検証済みのテストやビルドの繰り返しを省きます。旧方式で生成したartifactは対象外です。[公開手順](https://github.com/wamukat/kanbalone/blob/v1.1.0-rc.2/docs/ja/developer/release.md)
- アプリの変更はバージョン更新のみです。v1.1.0-rc.1からの更新に伴う追加のAPI互換性変更、DB移行、画像保存形式の変更はありません。

### v1.0.0から更新する場合

- チケット本文とコメントの画像添付、Groupの進捗・タグ表示と未所属一覧、キーボード操作、ボード表示の効率化、チケット一覧APIの任意ページングなど、v1.1.0-rc.1の変更を引き継ぎます。[v1.1.0-rc.1の変更点と制約](https://github.com/wamukat/kanbalone/blob/v1.1.0-rc.1/docs/releases/v1.1.0-rc.1.md#日本語)
- 更新前にSQLiteと添付画像の整合したバックアップを取得してください。旧版へ戻す場合は、旧イメージと更新前のバックアップを使います。ローカル画像を含むボードのJSON Exportは形式3となり、v1.0.0以前にはImportできません。[更新とバックアップの手順](https://github.com/wamukat/kanbalone/blob/v1.1.0-rc.2/docs/ja/migration-guide.md)

## English

This is the second v1.1.0 release candidate. GitHub’s latest stable release and the Docker `latest` tag remain at v1.0.0.

### Changes since v1.1.0-rc.1

- The publication workflow now uses a candidate artifact ID to publish the Docker image built and tested in the dry run and verified locally. Publication checks the candidate’s origin and integrity and skips the repeated build and test steps. Artifacts from the previous workflow are ineligible. [Release procedure](https://github.com/wamukat/kanbalone/blob/v1.1.0-rc.2/docs/en/developer/release.md)
- The application change is a version bump. Upgrading from v1.1.0-rc.1 introduces no further API compatibility changes, database migrations or image storage format changes.

### Upgrading from v1.0.0

- This candidate carries forward the v1.1.0-rc.1 changes, including images in ticket bodies and comments, Group progress and tags, the No Group view, keyboard shortcuts, faster board rendering and opt-in ticket list API pagination. [v1.1.0-rc.1 changes and limitations](https://github.com/wamukat/kanbalone/blob/v1.1.0-rc.1/docs/releases/v1.1.0-rc.1.md#english)
- Take a consistent backup of SQLite and image attachments before upgrading. To roll back, use the previous image with the pre-upgrade backup. A board export containing local images uses format 3 and requires v1.1.0-rc.1 or a later compatible version to import. [Upgrade and backup procedures](https://github.com/wamukat/kanbalone/blob/v1.1.0-rc.2/docs/en/migration-guide.md)
