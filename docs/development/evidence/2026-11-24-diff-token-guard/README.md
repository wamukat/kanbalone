1. 外部Issueの保存済み本文とローカル本文を持つチケットを合成データに用意します。両本文には共通行が3行あり、文言が異なる箇所が2箇所あります。比較する各ビルドに同じDBの複製を使いました。

3. 期待する表示は外枠、変更行の背景、追加・削除記号と本文です。全7行で、行の下辺と記号欄右辺は変更前後とも0 px、差分外枠は1 pxでした。各テーマ内で画像ファイルはバイト単位で一致し、行の位置・寸法・背景色も一致しました。
