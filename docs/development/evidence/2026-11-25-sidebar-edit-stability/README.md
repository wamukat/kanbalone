## 観察と結果

- 変更前は、タグの編集フォームを開くとサイドバーに縦スクロールバーが現れ、内幅が279 pxから268 pxになりました。ボード一覧とビュー切り替えは247 pxから236 pxになり、ボード設定アイコンは11 px左へ動きました。
- サイドバーの縦方向のFlexレイアウトにより、ボード追加ボタンは32 × 32 pxから32 × 18 pxに縮み、ビュー切り替えが14 px上に動きました。合成ボードの高いビューポートでスクロールバーが不要な場合、および低いビューポートで最初から表示される場合は、開閉時の横幅変化を再現しませんでした。
- 変更後はスクロールバーの出る位置にあらかじめ空きを確保するため、開閉を通してサイドバーの内幅は268 px、ボード一覧とビュー切り替えは236 pxです。ボード追加ボタンは32 × 32 px、編集欄より上にある要素の位置と寸法は一定でした。ボード設定とカスタムビューは同じ寸法・外観で、編集フォームが広がった分だけ下へ移動しました。
- 編集中にサイドバーをスクロールでき、未フォーカスの `#336699` が末尾まで表示されました。キャンセル後は編集前の配置に戻り、取得APIのタグ名と色は編集前の値と一致しました。

計測値はこのブラウザーでのスクロールバーの表示に依存します。オーバーレイ表示や他のOS・ブラウザーの外観は検証範囲外です。
