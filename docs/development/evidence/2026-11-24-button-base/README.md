## スタイルと操作の確認

- 日本語・英語各1440 × 900の明暗と、日本語ダーク800 × 900で比較した。設定欄の通常表示、エクスポート・インポート・削除の各hover、Tabでエクスポートにフォーカスした状態、削除確認を確認した。歯車、エクスポート、取り込みラベル、削除、各アイコンと確認ダイアログの代表要素について、30条件の190要素でcomputed styleの562プロパティと矩形位置・寸法が一致した。
- 独立したPlaywright確認で、両版のインポートラベルのクリックがJSON用の非表示ファイル入力のファイル選択を開くことを確認した。ハーネスから空選択を返し、API書き込み0件と保存済みボード一覧の一致を確認した。
- 変更後の既存E2E 13件が通過した。ボード設定テストではエクスポート要求とダウンロード開始、ファイル名、削除後の保存結果、エクスポートしたJSONの再取り込みとボード表示を確認した。Webビルドと公開フロントエンドの型検査も通過した。 [ボード設定のE2E](../../../../test/e2e/board.spec.ts)・[表示トークンのE2E](../../../../test/e2e/layout-visual-system.spec.ts)・[狭幅とツールバーのE2E](../../../../test/e2e/layout-toolbar.spec.ts)

画像は通常表示と確認画面の記録。hoverとフォーカスは実測で比較した。OS固有のファイル選択ダイアログの表示や手動での取消、Chromium系以外のブラウザーでの検証は今回の範囲外。
