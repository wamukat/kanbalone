## 見た目の確認

1. 合成ボード `Design Studio` の `Intake` レーンで新規チケットエディターを開き、リモート取り込みを開きます。
2. 模擬GitHubのIssue URLを入力し、リンク付きコメントを投稿するチェックボックスをSpaceで選択します。
3. Kanbalone URLを入れ、Issueをプレビューします。チェックボックスへフォーカスを戻して撮影します。

変更前の入力要素は幅467 × 高さ13 pxで、ラベルは次の行でした。変更後は13 × 13 pxで、ラベルが7.7 pxの間隔で横に並びます。チェックボックスとラベルは上下中央で揃い、URL入力は467 pxの幅を維持しています。

## 操作と保存

- ブラウザーの当たり判定でラベル文字を確認してクリックし、ネイティブの `change` とURL入力の有効化を記録しました。
- Spaceでオフにすると入力値が消え、URL欄が非表示かつ無効になりました。再度Spaceで有効化できました。
- キャンセルで取り込みを閉じると、新規チケットのタイトル入力を保持し、取り込みボタンへフォーカスが戻りました。再表示では取り込みフォームの値が初期状態になりました。キャンセルによる保存はありませんでした。
- チェックあり・なしの取り込みを1件ずつ実行し、双方がHTTP 201を返すことと、正しいボード・レーンへ保存されることを再取得で確認しました。チェックありの要求にはURLを含み、模擬コメント投稿は1件でした。チェックなしの要求はURLを送らず、模擬コメント投稿はありませんでした。[ブラウザー操作・受信ペイロード・保存結果](interaction.json)

外部サービスは模擬アダプターです。OS固有のチェックマークの形状や、実プロバイダー側の投稿挙動は今回の観測範囲外です。
