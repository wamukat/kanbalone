# タグ色スイッチの余白

2026年11月25日 JST に macOS の Headless Chromium 158、デバイス画素比1、日本語で撮影しました。変更前は `b1ff9cfb8d793e05895df6370ba1a2507ce763a2`、変更後は同じソースにタグ編集のスイッチ枠と狭い幅の配置を調整した候補です。いずれも v1.4.0 と表示されます。合成ボードを同じ時点から複製し、各組のビュー幅、配色、操作、タグ値 `#336699` を揃えました。[ソースと画像のハッシュ・計測値](manifest.json)

## 表示の結果

期待は、スイッチの外枠に左右均等な余白があり、16進値と色見本をあわせて確認できることです。既定のサイドバー幅280 pxでは、外枠内の左右の空きが各8.69 pxから14 pxになり、3つのコントロールは1行に並びました。幅240 pxのビューポートではサイドバーが実測229 pxで、変更前の外枠内に左右の空きがありませんでした。変更後は左右各14 pxになり、スイッチの下に16進欄と色見本が並びました。

色の行の実幅が210 px未満で2行に切り替わることを、境界の両側で確認しました。変更後は全8状態で16進欄の `clientWidth` と `scrollWidth` が一致し、スクロール位置0で `#336699` の末尾まで表示されました。スイッチ、16進欄、ピッカーはタグ編集フォーム内に収まりました。

## 操作と保存の結果

- Tab でタグ名からスイッチ、16進欄へ移動し、スイッチにフォーカス輪郭が出ました。Space とラベルクリックで色を切り替え、オフでは16進欄とピッカーが無効になりました。
- 16進欄への `#DDDDDD` の入力がピッカーに反映されました。ネイティブ色入力に送った合成の `input` イベントでは、16進欄に `#25476B` が反映されました。
- 編集をキャンセルした後の取得APIは元の `#336699` を返しました。続けて `#DDDDDD` を保存し、APIの値と再読み込み後の16進欄とピッカーの表示を照合しました。

確認範囲は上記のChromium環境です。ネイティブカラーダイアログの表示と実機での操作は検証範囲外です。
