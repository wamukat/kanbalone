# カタログの現行契約への入口

日本語、ライト、1440 × 900 pxで、別途起動したUI部品カタログのインデックスを比較しました。アプリ本体への操作はありません。

- [変更前のインデックス原画像](before-index.png)には、現行の部品契約へのリンクがありません。
- [変更後のインデックス原画像](after-index.png)では、サイドバーと本文に現行の部品契約への入口があります。
- サイドバーの入口にフォーカスし、Enterで[現行契約ページ](after-contract.png)へ移動することを確認しました。

変更前は2026年11月24日に現行契約の入口追加前のビューアーから保存した原画像です。当時の作業ツリーと生成HTML一式が残っていないため、厳密なソース指紋や、本文の他の差分まで一致する比較はできません。入口の追加と移動先を確認する証拠として記録しています。[画像ハッシュと移動先の記録](manifest.json)
