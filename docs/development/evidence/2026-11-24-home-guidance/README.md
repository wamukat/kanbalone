空の合成DBから起動し、日本語と英語の明暗4条件を比較しました。ブラウザーはHeadless Chromium 158、1440 × 900 px、画素比1です。画像採取ではアニメーションの進行による差を避けるため、動きの軽減を有効にしました。撮影日は2026年11月24日です。

変更前の案内は全4条件で「Create board here」でした。変更後は日本語で「最初のボードを作成」、英語で「Create your first board」と表示され、ボタンのアクセシブルな名前と一致しました。ボタンの位置と大きさ、案内の幅、前景色と背景色の計算値は前後で同じです。

## 初回操作と保存

1. 空ホームで＋ボタンをキーボードで開き、フォーカスがボード名に移ることを確認しました。
2. 名前を入力してEscapeで取り消しました。案内が戻り、APIでボードは0件でした。
3. 再びボード名を入力してEnterで作成しました。ボードとレーンの保存を取得で確認し、画面を再読み込みして同じボードが開くことを確認しました。
4. 作成後は初回の案内が消え、＋ボタンの名前が日本語の「新しいボード」または英語の「New board」になりました。

日英双方で保存まで確認しました。日本語の動き軽減ではアニメーションが無効、英語の通常設定ではアニメーションが有効でした。Chromiumの関連E2Eは i18n と board の16件が通過しました。[操作・再取得記録](interaction.json)
